# Contact Access

### Descrição
O **Contact Access** é um aplicativo mobile que acessa os contatos armazenados no dispositivo do usuário. O app foi desenvolvido utilizando a biblioteca do **Expo** para acesso às informações de contatos, permitindo funcionalidades como listagem e visualização de detalhes.

---

## Funcionalidades

- **Listar contatos**: Exibe uma lista com todos os contatos salvos no dispositivo.
- **Exibir detalhes**: Permite visualizar informações detalhadas de cada contato, como números de telefone e e-mails.
- **Busca de contatos**: Facilita encontrar contatos específicos com um campo de busca (opcional).

---

## Tecnologias Utilizadas

- **Framework**: React Native
- **Gerenciamento de dependências**: Expo CLI
- **Acesso aos contatos**: [expo-contacts](https://docs.expo.dev/versions/latest/sdk/contacts/)

---

## Como executar o projeto

### Pré-requisitos

- Node.js instalado
- Expo CLI configurado
- Editor de código (VSCode recomendado)
- Dispositivo físico ou emulador configurado

### Passos

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/contact-access.git
   ```
2. Instale as dependências:
   ```bash
   cd contact-access
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   expo start
   ```
4. Escaneie o QR Code com o aplicativo Expo Go no seu dispositivo ou use um emulador.
